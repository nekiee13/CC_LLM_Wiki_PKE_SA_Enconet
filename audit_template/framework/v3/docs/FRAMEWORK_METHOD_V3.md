# Reusable audit framework v3

This is code and common method, not another company's audit. Local runtime uses
only this project's script copies, configuration, documents and decisions.

1. Keep sources in incoming. Intake previews first and preserves incoming bytes.
2. Confirm local scope, language and regulatory editions. Register approved sources.
3. Initialize the local database and preserve full chapter text and provenance.
4. Use full keyword/concept recall. Calibrate and activate prompts locally.
   Collect broad useful evidence, but keep quotes exact and uncertainty visible.
5. Record applicability and five-level documentary judgments with local approvals.
   Part 21 stays separate. FAHP and manual judgment-entry forms are not added.
6. Build one evaluation package, its evidence bundle, report and light dashboard.
   Use the documentary report option for arguments and stored criterion scores.
   Candidate report/viewer outputs go under outputs/candidates/evidence_access/RUN-id.
7. Build a separate dark copy from the verified light HTML. Never overwrite light.
   Audit JavaScript, source chapters and print behavior remain unchanged.
8. Validate quotes, report links, portable package, browser behavior and sizes.
   Browser runtime is local or configured by PLAYWRIGHT_BROWSERS_PATH; no sibling
   project or machine-specific path is compiled into the framework.
9. Release only under local G5/G6 decisions and applicable review policy. The
   first-release publisher refuses existing targets and restores Windows folder
   permissions. Its deferred-review mode also needs an explicit local owner
   exception that pins the exact release plan. Another company's exception is invalid.
10. Reset requires a reviewed local plan and that company's backup decision.
    Incoming, code and required history remain. No reset is run during setup.

The default capacity profile is the small baseline. A separate 1 MiB viewer/bundle
candidate is supplied; selecting it requires a local signed fingerprint-bound
capacity decision. No source edition, calibration, size approval, reviewer claim,
generation decision, score or no-backup waiver transfers to a new audit.

The framework also retains the prior presentation builder as a compatible view.
New report/evidence delivery uses the current package and native dashboard stack.
Claude infrastructure is not included; synchronization and review remain pending.
