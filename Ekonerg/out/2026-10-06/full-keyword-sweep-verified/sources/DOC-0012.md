## 1. UVOD

### 1.1. Opseg

Postupak se odnosi na kontrolne postupke tj. radne postupke za provedbu nadzora nad primjenom sustava kvalitete i aktivnosti drugih organizacija, koje suradnici EKONERG-a koriste u kontroli provedbe aktivnosti.

### 1.2. Svrha

Svrha je ovog postupka definirati odgovornost za pripremu, pregled, revizije i promjene, te standardni format za pripremu kontrolnih postupaka.

### 1.3. Reference

HRN EN ISO 9001 važeće izdanje

## 2. ODGOVORNOST

1. 1.1. Suradnik u EKONERG-u zadužen od strane Voditelja Q/EP/HS službe ili Direktora odjela odgovoran je za pripremu kontrolnog postupka po kojem se kontrola neke aktivnosti obavlja.
2. 1.2. Voditelj Q/EP/HS službe ili osoba koju odredi Voditelj Q/EP/HS službe odgovoran je za pregled kontrolnog postupka, te njegovih promjena i revizija.
3. 1.3. Direktor EKONERG-a odgovoran je za odobrenje kontrolnog postupka, te njegovih promjena i revizija.

## 3. KONTROLNI POSTUPCI

### 3.1. Sadržaj kontrolnih postupaka

Kontrolni postupak sastoji se od 5 točaka s podtočkama kako slijedi:

1. 1. SVRHA I OPSEG - treba ukratko obrazložiti svrhu pripreme postupka i opseg aktivnosti na koji se primjenjuje
2. 2. REFERENTNI PROPISI I ZAHTJEVI - treba navesti propise ili zahtjeve iz propisa koji se odnose na kontroliranu aktivnost
3. 3. POSTUPAK KONTROLE a) Preduvjeti - ukratko treba opisati preduvjete za pristupanje aktivnosti

![](../../../../../_resources/_page_2_Picture_1-11.jpeg)

| b) Provedba kontrole                                       | - ukratko opisati što se sve u toku aktivnosti kontrolira i na koji način                                 |
|------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------|
| c) Dokumentacija kojom se registrira obavljanje aktivnosti | - ukratko navesti koju sve dokumentaciju treba generirati izvoditelj aktivnosti i što ona mora sadržavati |
| 4. DOKUMENTACIJA                                           | - navesti kako se dokumentira kontrola aktivnosti                                                         |
| 5. PRILOZI                                                 | - navesti priloge koji se koriste u postupku kontrole (npr. kontrolne liste, izvodi iz propisa i sl.)     |

### **3.2. Format kontrolnih postupaka**

3.2.1. Kontrolni postupci pripremaju se na obrascu PQ.4-3.1 u prilogu A (naslovna stranica) i PQ.4-3.2 u prilogu B (slijedna stranica) ovog postupka.

3.2.2. Kontrolni postupci imaju naslove koji definiraju njihov sadržaj.

3.2.3. Oznaka kontrolnog postupka sastoji se od alfabetskog i numeričkog dijela:

- – alfabetski dio označava kojem području aktivnosti pripada postupak, kako slijedi:

| KSPR | - kontrola specijalnih procesa (zavarivanje, toplinska obrada) |
|------|----------------------------------------------------------------|
| KFIS | - kontrola funkcionalnih ispitivanja                           |
| KBIS | - kontrola bezrazornih ispitivanja                             |
| KSMA | - kontrola svojstava materijala                                |
| KTPN | - kontrola tlačne probe i probe nepropusnosti                  |
| KDOP | - kontrola dimenzija, oblika i obrade površina                 |
| KAKZ | - kontrola antikorozivne zaštite                               |
| KVBB | - kontrola vibracija, balansiranja i buke                      |
| KPAK | - kontrola proizvodnih aktivnosti                              |
| KRAK | - kontrola remontnih aktivnosti                                |
| KMAK | - kontrola montažnih aktivnosti                                |
| KSPA | - kontrola studijskih/projektnih aktivnosti                    |
| KUSL | - kontrola izvođenja raznih usluga                             |
| KDOK | - kontrola dokumentacije                                       |
| KOST | - kontrola ostalih aktivnosti                                  |

- – numerički dio se sastoji od arapskog broja, koji predstavlja broj postupka

Npr. KSPR-2 predstavlja postupak br. 2 iz područja specijalnih procesa.

![](../../../../../_resources/_page_3_Picture_1-12.jpeg)

- 3.3.1 Kontrolni postupak te njegove revizije i promjene priprema suradnik u EKONERG-u ili druga osoba koju na temelju njenog specijalističkog znanja određuje Direktor odjela ili Voditelj Q/EP/HS službe.
- 3.3.2 Kontrolni postupak te njegove revizije i promjene pregledava suradnik u EKONERG-u ili druga osoba, određena od Voditelja Q/EP/HS službe, koja posjeduje specijalističko znanje i nije sudjelovala u pripremi postupka.
- 3.3.3 Kontrolni postupak te njegove revizije i promjene odobrava Direktor EKONERG-a.
- 3.3.4 Pregled i odobrenje postupka, te revizija i promjena označava se potpisom.
- 3.3.5 Broj revizije označava se na prvoj strani, te svim slijednim stranama postupka.
- 3.3.6 Ako se dodaje stranica, imat će uz broj alfabetski dodatak.

#### 4. SPREMANJE I ČUVANJE

Kopije kontrolnih postupaka dostavljaju se svim suradnicima EKONERG-a, koji prema njima provode kontrolne aktivnosti, u skladu s distribucijskom listom koju vodi Voditelj Q/EP/HS službe.

Originali kontrolnih postupaka čuvaju se u arhivi Q/EP/HS službe EKONERG-a.

Važeći popis kontrolnih postupaka, kao i važeća revizija svih novorazvijenih kontrolnih postupaka objavljeni su na intranet stranici EKONERG-a.
