# Ekonerg coordination

This is the project-local agent channel for Ekonerg.

- Active requests live in `messages/`.
- Resolved records and resolution manifests live in `archive/`.
- Task ownership records live in `claims/`.
- `BOARD.md` is generated by `Ekonerg/scripts/agent_coord.py status --write`.
- `TEAM_PROTOCOL.md` defines the shared message and claim rules.

Do not use the Enconet queue for Ekonerg work. Enconet keeps its own project and
workspace-level coordination records.
