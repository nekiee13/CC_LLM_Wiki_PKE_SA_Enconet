each original file unchanged. No subfolder scheme is assumed.

it applies, or add it to an audit run. Codex will first inventory and hash the
files, record where each came from, and ask for the missing scope and intake
decisions in the later source-intake task. No program should scan this folder
as an approved source set until those gates are complete. Unsupported formats
must be reported before any processing.

This drop-off may contain sensitive QMS material. Access, storage, backup, and
retention choices remain for the owner to confirm before intake. Do not move
or edit an owner's uploaded files without approval. The files already present
were not read, hashed, moved, or processed in this EK-1.2 support-tool batch.
