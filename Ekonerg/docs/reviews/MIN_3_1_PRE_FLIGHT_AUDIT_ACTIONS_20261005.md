## Execution order

1. Run PF-01 through PF-05 as a short scope interview and document check.
2. Select representative work for PF-06 and PF-07.
3. Select one closed or recently completed case for PF-08.
4. Use the same samples to perform PF-09 and avoid duplicate requests.
5. Record each result against the existing Appendix B criterion and crumb IDs.
6. Only after this evidence review should formal ratings, findings, actions,
   or a consolidated score be entered in the audit database.

## Status rule

An unanswered action is an open evidence request. It is not automatically a
failed criterion, a final N/A decision, or a Part 21 reportability decision.
