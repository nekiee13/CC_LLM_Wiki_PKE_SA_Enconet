# 1 INTRODUCTION

## 1.1 Purpose

The purpose of this procedure is to describe methods for software installation, keeping, handling and maintenance. This procedure applies to all software used for performing activities described in ENCONET Quality Assurance Program. This procedure affects personnel involved in the software installation keeping, handling and maintenance.

## 1.2 Scope

This procedure gives instructions for software installation, storage control and control of physical media, and software maintenance dependable upon the form of the software available in ENCONET d.o.o.

### 2.2 Definitions

1. Software Installation – The process of restoring software from external media to a local file system and preparation of conditions to be used on PC/workstation.

2. Control of the physical media and associated services – all functions, which are carried out to ensure that the data or software stored, are physically retrievable and cannot be lost or compromised due to any day to day operations or possible catastrophic events.

3. Software Maintenance – the process of modifying a software system or component, after delivery, to correct faults, improve performance or other attributes, adapt to a changed environment, or add new functionality.

4. Software Maintenance Documentation – provides information on how to support the software during its operational life.

5. Test Case – a specific set of test data and associated procedures developed for particular objective.

# 4 INSTRUCTIONS

## 4.1 Installation

### 4.1.1 Verification of Installation Package

#### 4.1.1.1 Check the availability of the necessary elements from the following list.

1. Installation instructions
2. Existence of all files specified in installation instructions
3. Test Cases
4. Output produced by the test cases

#### 4.1.1.2 Check that the format and content of the media are properly identified in the installation procedures.

### 4.1.2 Installation shall be performed according to installation procedure provided within software documentation or using automatic installation procedure if provided with original software.

### 4.1.3 The installation date and hardware platform shall be recorded in installation log list.

### 4.1.4 The accompanying test cases shall be used for testing of successfulness of the installation.

## 4.2 Storage control and control of physical media

4.2.1 The original of the maintained software package is kept in central
      archive room.

4.2.2 Backup recording of original distribution media
      1. External software – immediately after software purchase
      2. Internally generated software – after successful termination of testing
         phase and after recording of original software copy

4.2.3 Installation of the software is performed using backup copy.

4.2.4 Backup shall be made with the disk copy utility on local HD drive,
      separately on the CD/DVD media and on the ENCONET d.o.o. server in
      the Software Backup directory.

4.2.5 The list of the stored original software packages is written in Computer
      Software List OB-CSL-051 (Appendix Error! Reference source not
      found.).

4.2.6 List of the backup copies of original software is written in OB-CSA-052
      (Appendix 0).

4.2.7 The original software packages have unlimited storage time (permanent
      storage).

4.2.8 It is responsibility of software engineer to distribute adequate version of
      software according to the request from project manager.

4.2.9 Backup files are temporary storage.

    4.2.9.1 All kinds of data contained in backups are finally stored inside
            other categories of records when they are finished (project
            documentation and archives, software packages, data records,
            etc.).

    4.2.9.2 The files in this category are kept for period of time requested for
            project documentation.

4.2.10 Following kinds of computer media can be stored in software archive:

    1. CD/DVD media.
    2. For some old packages source listings.

4.2.11 Every two year content of above mentioned media has to be verified.

4.3 Software maintenance

4.3.1 The software maintenance process is dependable upon the form of the
      software available in ENCONET d.o.o.

    4.3.1.1 Software available only in the form of executable shall be
            maintained to assure that the version is compatible with the
            verified environment (operating system version and hardware).

    4.3.1.2 Software available in the form of the source code or precompiled
            routines and libraries shall be maintained for the same conditions
            as 4.3.1.1 with addition of checking of compatibility with compiler
            or other supporting programming tools.
